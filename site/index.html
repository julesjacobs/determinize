Determinize

Type inference finds the random draws in a probabilistic program that can be replaced by the means of their distributions. For domain-safe programs of type float[E], the replacement keeps the expected output and does not increase its variance.

The signal example

Source (modes inferred)

let x = uniform[G](0, 1) in
let y = gaussian[E](x, 1) in
x * y

Determinized

let x = uniform[G](0, 1) in
let y = mean_gauss(x, 1) in
x * y

Why the expected output stays the same: for each value of x, the determinized program returns the source’s average over the noise y.

What is proved

For a closed program e (program in Lean) of type float[E] that is domain-safe (DomainSafe), and its determinization (Expr.determinize):

  1. it returns with the same probability as e;

    returnProbability program.determinize = returnProbability program
    output_mass_preservation

  2. if e returns with positive probability and its expectation is defined, the same holds for its determinization, and its expected output given that it returns equals e’s, possibly infinite;

    0 < returnProbability program.determinize ∧
  HasExpectation (bigStepMeasure program.determinize) ∧
  returnedExpectation program.determinize = returnedExpectation program
    expectation_preservation

  3. if e returns with positive probability and has a finite second moment, the same holds for its determinization, and its variance given that it returns is at most e’s;

    0 < returnProbability program.determinize ∧
  MemLp id 2 (bigStepMeasure program.determinize) ∧
  returnedVariance program.determinize ≤ returnedVariance program
    variance_non_increase

  4. for almost every terminating G trace, it returns e’s mean output given that trace.

    ∀ᵐ trace ∂traceLaw program,
  Integrable id ((traceAndOutputLaw program).condKernel trace) ∧
  (traceAndOutputLaw program.determinize).condKernel trace =
    Measure.dirac (∫ value : ℝ, value ∂(traceAndOutputLaw program).condKernel trace)
    tracewise_soundness

Inference fails only when no assignment of modes agrees with the modes written in the program. Otherwise it returns the assignment with the most E draws: every draw that some valid assignment marks E is marked E (inference_correctness). Domain safety and integrability are premises; typing does not establish them.

The simulator is an unverified visualization. The Lean development, its command-line tool and the theorems above are the checked artefacts.
