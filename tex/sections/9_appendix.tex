\section{Gaussian Random Walk}
\label{sec:appendix-gauss-random-walk}

The full source program of \cref{fig:intro-gaussian-walk}, from~\cite{vakar2019domain},
is shown below. \texttt{reduce} folds the step function over the requested times,
starting from the path that contains only $(0,0)$.

\begin{lstlisting}
let reduce =
  rec reduce f => fun accumulator => fun xs =>
    match xs with
    | [] =>
        accumulator
    | x :: rest =>
        reduce f (f accumulator x) rest
in

let step =
  fun path => fun nextTime =>
    match path with
    | [] =>
        []
    | current :: previous =>
        let time = fst current in
        let position = snd current in
        let nextPosition =
          gauss(position, nextTime - time)
        in
        (nextTime, nextPosition) :: path
in

let times =
  1 :: 2 :: 4 :: 5.5 :: 6 :: 6.25 :: []
in

reduce step ((0, 0) :: []) times
\end{lstlisting}

\section{Determinization}
\label{sec:appendix-determinization}

We give the full structural definition of the transformation in
\cref{def:determinization}\leanref{determinization}, covering every constructor
in \cref{fig:syntax}. To keep the rules compact, we abbreviate recursive
calls throughout this section by
\[
  e'=\trans{e},
  \qquad e_i'=\trans{e_i}.
\]
Thus, each primed expression denotes the determinization of its unprimed
counterpart. Bound variable names are unchanged.
For each distribution mode $\alpha$, let
\[
  \alpha'=
  \begin{cases}
    \M & \alpha=\E,\\
    \G & \alpha=\G,\\
    \M & \alpha=\M.
  \end{cases}
\]



\paragraph{Variables and constants.}
\begin{align*}
  \trans x &= x,&
  \trans r &= r \quad(r\in\Real),\\
  \trans{()} &= (),&
  \trans{\kw{true}} &= \kw{true},\\
  \trans{\kw{false}} &= \kw{false},&
  \trans{\kw{reject}} &= \kw{reject},\\
  \trans{[]} &= [].
\end{align*}

\paragraph{Functions, recursion, and control flow.}
\begin{align*}
  \trans{\lambda x.e} &= \lambda x.e',\\
  \trans{\recfn f x e} &= \recfn f x{e'},\\
  \trans{e_1\,e_2} &= e_1'\,e_2',\\
  \trans{\letin x{e_1}{e_2}} &= \letin x{e_1'}{e_2'},\\
  \trans{\ite{e_0}{e_1}{e_2}} &= \ite{e_0'}{e_1'}{e_2'}.
\end{align*}

\paragraph{Arithmetic and comparisons.}
\begin{align*}
  \trans{-e} &= -e',\\
  \trans{e_1+e_2} &= e_1'+e_2',\\
  \trans{e_1\cdot e_2} &= e_1'\cdot e_2',\\
  \trans{e_1/e_2} &= e_1'/e_2',\\
  \trans{e_1<e_2} &= e_1'<e_2'.
\end{align*}

\paragraph{Pairs, sums, and lists.}
\begin{align*}
  \trans{\langle e_1,e_2\rangle} &= \langle e_1',e_2'\rangle,\\
  \trans{\kw{fst}\,e} &= \kw{fst}\,e',\\
  \trans{\kw{snd}\,e} &= \kw{snd}\,e',\\
  \trans{\kw{inl}\,e} &= \kw{inl}\,e',\\
  \trans{\kw{inr}\,e} &= \kw{inr}\,e',\\
  \trans{e_1::e_2} &= e_1'::e_2'.
\end{align*}
\begin{align*}
  \trans{\scase{e_0}x{e_1}y{e_2}}
    &={}\\[-2pt]
    &\quad\scase{e_0'}x{e_1'}y{e_2'},\\[4pt]
  \trans{\lcase{e_0}{e_1}x{xs}{e_2}}
    &={}\\[-2pt]
    &\quad\lcase{e_0'}{e_1'}x{xs}{e_2'}.
\end{align*}

\paragraph{Distribution expressions.}
For all $\alpha\in\{\G,\E,\M\}$, the eight primitive distributions transform as
follows:
\begin{align*}
  \trans{\draw{uniform}\alpha{e_1,e_2}}
    &= \draw{uniform}{\alpha'}{e_1',e_2'},\\
  \trans{\draw{gaussian}\alpha{e_1,e_2}}
    &= \draw{gaussian}{\alpha'}{e_1',e_2'},\\
  \trans{\draw{poisson}\alpha e}
    &= \draw{poisson}{\alpha'}{e'},\\
  \trans{\draw{exponential}\alpha e}
    &= \draw{exponential}{\alpha'}{e'},\\
  \trans{\draw{bernoulli}\alpha e}
    &= \draw{bernoulli}{\alpha'}{e'},\\
  \trans{\draw{discrete}\alpha e}
    &= \draw{discrete}{\alpha'}{e'},\\
  \trans{\draw{beta}\alpha{e_1,e_2}}
    &= \draw{beta}{\alpha'}{e_1',e_2'},\\
  \trans{\draw{gamma}\alpha{e_1,e_2}}
    &= \draw{gamma}{\alpha'}{e_1',e_2'}.
\end{align*}
The target retains each distribution primitive and all its arguments; only
$\E$ changes to $\M$, and every argument is recursively transformed.
Mean evaluation remains an atomic distribution operation, governed by the
domain conditions and reduction rule in \cref{fig:semantics}.

\section{Determinization Examples}\label{sec:appendix-determinization-examples}

\begin{example}[Full determinization]
Consider an $\E$-mode Gaussian whose mean is given by an
$\E$-mode uniform distribution. Determinization changes the
outer Gaussian to $\M$-mode and recursively transforms its
arguments. In particular, the nested $\E$-mode uniform
distribution is also changed to $\M$-mode:
\begin{align*}
\trans{
  \kw{gaussian}^{\E}
    \bigl(\kw{uniform}^{\E}(0,1),1\bigr)}
&=
\kw{gaussian}^{\M}
  \bigl(
    \trans{\kw{uniform}^{\E}(0,1)},
    1
  \bigr)
\\
&=
\kw{gaussian}^{\M}
  \bigl(
    \kw{uniform}^{\M}(0,1),
    1
  \bigr).
\end{align*}
Thus, both sampling sites are replaced by mean evaluations,
yielding a deterministic program.
\end{example}

\begin{example}[Partial determinization]
Consider a program with dependent random draws.
The $\G$-mode uniform distribution remains stochastic,
while the $\E$-mode Gaussian is changed to $\M$-mode.
Crucially, the Gaussian's mean $2x+1$ still depends
on the random value of $x$:
\[
\trans{\left(
\begin{aligned}
&\kw{let}\ x=\kw{uniform}^{\G}(0,1)\ \kw{in}\\
&\kw{let}\ y=\kw{gaussian}^{\E}(2x+1,\sigma^2)\ \kw{in}\\
&x*y
\end{aligned}
\right)}
=
\begin{aligned}
&\kw{let}\ x=\kw{uniform}^{\G}(0,1)\ \kw{in}\\
&\kw{let}\ y=\kw{gaussian}^{\M}(2x+1,\sigma^2)\ \kw{in}\\
&x*y.
\end{aligned}
\]
Thus, determinization eliminates the Gaussian's
conditional randomness while preserving its dependence
on the retained random value of $x$.
\end{example}

\section{Constraint Generation Rules}
\label{sec:appendix-constraint-generation}

We give the full constraint-generation rules for every construct in
\cref{fig:syntax}, including those selected for \cref{fig:inference}.
The judgment $\Gamma\vdash e\Rightarrow\tau\mid C$ infers a type $\tau$
and the complete constraint set $C$. Each rule explicitly includes the
constraints generated by its subexpressions and any additional requirements.
Type and affinity variables declared fresh are distinct from all variables
already in use. Bindings are monomorphic.

\paragraph{Compact summary.}
The following table summarizes constraint generation for arithmetic
expressions and distributions. For each operand,
$\Gamma\vdash e_i\Rightarrow\tau_i\mid C_i$. Each displayed $a$ is fresh;
the complete constraint set is $\bigcup_i C_i$ together with the listed
constraints. At a sampling site, $a$ supplies the inferred annotation;
an explicit annotation $m\in\{\G,\E\}$ additionally generates $a=m$.
\begin{center}
\small
\renewcommand{\arraystretch}{1.25}
\begin{tabular*}{\linewidth}{@{}l@{\extracolsep{\fill}}ll@{}}
\toprule
Expression & Inferred type & Added constraints\\
\midrule
$r$ & $\tyR a$ & $\varnothing$\\
$-e_1$ & $\tyR a$ & $\tau_1<:\tyR a$\\
$e_1+e_2$ & $\tyR a$ & $\tau_1<:\tyR a,\quad\tau_2<:\tyR a$\\
$e_1\cdot e_2$ & $\tyR a$ & $\tau_1<:\tyR\G,\quad\tau_2<:\tyR a$\\

\section{Constraint Generation Example}\label{sec:appendix-constraint-generation-example}
\begin{example}[Constraint generation]
\label{ex:constraint-generation}
Consider the following program, with all sampling sites unannotated:
\[
\begin{aligned}
&\kw{let}\ x=\kw{uniform}(0,1)\ \kw{in}\\
&\kw{let}\ y=\kw{gaussian}(x,1)\ \kw{in}\\
&\kw{let}\ z=\kw{gaussian}(y,1)\ \kw{in}\\
&\kw{if}\ x<1/2\ \kw{then}\ x*z\ \kw{else}\ z+1.
\end{aligned}
\]
Let $a_x,a_y,a_z$ denote the fresh mode variables
associated with the three sampling sites.
By \textsc{Let} and \textsc{Var}, subsequent uses of
$x,y,z$ have types $\tyR{a_x},\tyR{a_y},\tyR{a_z}$,
respectively.
Similarly, applying the remaining rules in
\cref{fig:inference} generates the following
subtype constraints:
\[
\begin{aligned}
\tyR{a_x}<:\tyR{a_y},\quad
\tyR{a_y}<:\tyR{a_z}
  &\quad\text{(\textsc{Gaussian})}\\
\tyR{a_x}<:\tyR\G
  &\quad\text{(\textsc{Cmp}, \textsc{Mul})}\\
\tyR{a_z}<:\tyR{a_t},\quad
\tyR{a_z}<:\tyR{a_f}
  &\quad\text{(\textsc{Mul}, \textsc{Add})}\\
\tyR{a_t}<:X,\quad
\tyR{a_f}<:X
  &\quad\text{(\textsc{If})}.
\end{aligned}
\]
Here $a_f$ is the mode variable of the else branch's
result type, and $X$ is the fresh type variable
introduced by \textsc{If}.
We omit the constraints involving numeric constants
and the trivial Boolean guard constraint; these are
generated by the same rules.
\end{example}

\section{Constraint Solving Example}\label{sec:appendix-constraint-solving-example}

\begin{example}[Constraint solving]
Continuing \cref{ex:constraint-generation}, we apply
\cref{fig:inference-solving}. Shape unification succeeds and gives $X$
the shape of a real type. Decoration therefore replaces every occurrence
of $X$ by $\tyR b$ with the same fresh annotation variable $b$.
Subtype constraint reduction turns $\tyR{a_t}<:\tyR b$ and
$\tyR{a_f}<:\tyR b$ into $a_t\le b$ and $a_f\le b$.

The remaining real-type constraints reduce directly
to mode inequalities:
\[
\begin{gathered}
a_x\le a_y,\quad a_y\le a_z,\quad a_x\le\G,\\
a_z\le a_t,\quad a_z\le a_f,\quad
a_t\le b,\quad a_f\le b.
\end{gathered}
\]

Mode constraint solving forces $a_x=\G$,
since $a_x\le\G$. No other mode variables are
forced to $\G$, so all remaining variables are
assigned $\E$.
Thus, inference assigns the sampling sites
\[
(a_x,a_y,a_z)=(\G,\E,\E)
\]
and the program has type $\tyR\E$.
The inferred annotations yield the program:
\[
\begin{aligned}
&\kw{let}\ x=\kw{uniform}^{\G}(0,1)\ \kw{in}\\
&\kw{let}\ y=\kw{gaussian}^{\E}(x,1)\ \kw{in}\\
&\kw{let}\ z=\kw{gaussian}^{\E}(y,1)\ \kw{in}\\
&\kw{if}\ x<1/2\ \kw{then}\ x*z\ \kw{else}\ z+1.
\end{aligned}
\]
Determinization consequently retains the uniform
sample while replacing both Gaussian samples by
their conditional means. 
\end{example}

\section{Tracewise Soundness Theorem, by Example}\label{sec:appendix-trace-soundness-example}
\begin{example}
Consider
\[
\begin{aligned}
  &\kw{let}\ x=\kw{uniform}^{\G}(0,1)\ \kw{in}\\
  &\kw{let}\ y=\kw{uniform}^{\E}(-1,1)\ \kw{in}\ x+y.
\end{aligned}
\]
A trace records only the sampled value $x=r$. Given this trace, the
original program returns $r+y$, which is uniformly distributed on
$[r-1,r+1]$ and has expectation $r$. Determinization replaces the
sample $y$ by its mean, zero, so the transformed program returns $r$.
Thus, for each such trace $\tau$,
\[
  \Expect[e\mid\tau]=r,
  \qquad
  \law{\trans e}(\,\cdot\mid\tau)=\delta_r.
\]
The output still varies across traces, but within each trace
determinization replaces the remaining randomness by its average.
\end{example}

\section{Symbolic Semantics}
\label{sec:appendix-symbolic-definitions}

\subsection{Residual Expression Syntax}

\begin{definition}[Residual symbolic expressions]\label{sec:appendix-symbolic-definitions-residual-syntax}
Fix symbolic variables $u_1,\ldots,u_k$. Affine expressions and residual
symbolic expressions are given by the following grammar:
\[
\begin{aligned}
  a
  &::=
  c_0+\sum_{i=1}^{k}c_i u_i,
  \qquad c_0,\ldots,c_k\in\Real,
  \\
  \widehat e
  &::=
  x
  \mid\sym a
  \mid ()
  \mid \kw{true}
  \mid \kw{false}
  \mid \kw{reject}
  \\
  &\quad\mid
  \lambda x.\widehat e
  \mid \recfn f x{\widehat e}
  \mid \widehat e\,\widehat e
  \mid \letin x{\widehat e}{\widehat e}
  \\
  &\quad\mid
  \ite{\widehat e}{\widehat e}{\widehat e}
  \mid -\widehat e
  \mid \widehat e+\widehat e
  \mid \widehat e\cdot\widehat e
  \mid \widehat e/\widehat e
  \mid \widehat e<\widehat e
  \\
  &\quad\mid
  \langle\widehat e,\widehat e\rangle
  \mid \kw{fst}\,\widehat e
  \mid \kw{snd}\,\widehat e
  \\
  &\quad\mid
  \kw{inl}\,\widehat e
  \mid \kw{inr}\,\widehat e
  \mid \scase{\widehat e}{x}{\widehat e_1}{y}{\widehat e_2}
  \\
  &\quad\mid
  []
  \mid \widehat e::\widehat e
  \mid \lcase{\widehat e}{\widehat e_0}{x}{xs}{\widehat e_1}
  \\
  &\quad\mid
  \draw{uniform}\alpha{\widehat e,\widehat e}
  \mid \draw{gaussian}\alpha{\widehat e,\widehat e}
  \mid \draw{poisson}\alpha{\widehat e}
  \mid \draw{exponential}\alpha{\widehat e}
  \\
  &\quad\mid
  \draw{bernoulli}\alpha{\widehat e}
  \mid \draw{discrete}\alpha{\widehat e}
  \mid \draw{beta}\alpha{\widehat e,\widehat e}
  \mid \draw{gamma}\alpha{\widehat e,\widehat e},
  \\
  \alpha
  &::=\G\mid\E\mid\M.
\end{aligned}
\]
Thus, the residual grammar is the source grammar with each real literal
replaced by a wrapped affine expression $\sym a$. Symbolic coordinates $u_i$
are distinct from program variables bound by functions and pattern matching.
Substitution for program variables is capture avoiding.
\end{definition}

\paragraph{Values and evaluation contexts.}
Residual values and left-to-right evaluation contexts are:
\[
\begin{aligned}
\widehat v
  &::=\sym a\mid()\mid\kw{true}\mid\kw{false}
    \mid\lambda x.\widehat e
    \mid\recfn f x{\widehat e}\\
  &\quad\mid\langle\widehat v,\widehat v\rangle
    \mid\kw{inl}\,\widehat v
    \mid\kw{inr}\,\widehat v
    \mid[]\mid\widehat v::\widehat v,\\
\widehat C
  &::=[\,]\mid\widehat C\,\widehat e
    \mid\widehat v\,\widehat C
    \mid\letin x{\widehat C}{\widehat e}
    \mid\ite{\widehat C}{\widehat e_1}{\widehat e_2}\\
  &\quad\mid\langle\widehat C,\widehat e\rangle
    \mid\langle\widehat v,\widehat C\rangle
    \mid\kw{fst}\,\widehat C
    \mid\kw{snd}\,\widehat C
    \mid\kw{inl}\,\widehat C
    \mid\kw{inr}\,\widehat C\\
  &\quad\mid\widehat C::\widehat e
    \mid\widehat v::\widehat C
    \mid\scase{\widehat C}x{\widehat e_1}y{\widehat e_2}
    \mid\lcase{\widehat C}{\widehat e_0}x{xs}{\widehat e_1}\\
  &\quad\mid-\widehat C
    \mid\widehat C\mathbin\circ\widehat e
    \mid\widehat v\mathbin\circ\widehat C
    \mid\draw D\alpha{\bar{\widehat v},\widehat C,\bar{\widehat e}},
\end{aligned}
\]
where $\circ\in\{+,\cdot,/,<\}$ and
$\alpha\in\{\G,\E,\M\}$.

\subsection{Residual Expression Typing Rules}

\begin{definition}[Typing residual symbolic expressions]\label{sec:appendix-symbolic-definitions-residual-typing}
Residual symbolic expressions use the type grammar from \cref{fig:typing}.
The judgment $\typing{\widehat e}\tau$ is generated by the following rules.
The two affine-literal rules are the only rules that differ from the source
typing judgment.

\begin{mathpar}
  \inferrule*[right=Affine-E]
    {a=c_0+\sum_{i=1}^{k}c_i u_i}
    {\typing{\sym a}{\tyR\E}}
  \and
  \inferrule*[right=Affine-G]
    {a=c_0+\sum_{i=1}^{k}c_i u_i\\c_1=\cdots=c_k=0}
    {\typing{\sym a}{\tyR\G}}
  \and
  \inferrule*[right=Var]
    {x:\tau\in\Gamma}
    {\typing x\tau}
  \and
  \inferrule*[right=Unit]
    { }
    {\typing{()}\tyU}
  \and
  \inferrule*[right=True]
    { }
    {\typing{\kw{true}}\tyB}
  \and
  \inferrule*[right=False]
    { }
    {\typing{\kw{false}}\tyB}
  \and
  \inferrule*[right=Reject]
    { }
    {\typing{\kw{reject}}\tau}
\end{mathpar}

\begin{mathpar}
  \inferrule*[right=Lam]
    {\Gamma,x:\tau_1\vdash\widehat e:\tau_2}
    {\typing{\lambda x.\widehat e}{\tau_1\to\tau_2}}
  \and
  \inferrule*[right=Rec]
    {\Gamma,f:\tau_1\to\tau_2,x:\tau_1\vdash\widehat e:\tau_2}
    {\typing{\recfn f x{\widehat e}}{\tau_1\to\tau_2}}
  \and
  \inferrule*[right=App]
    {\typing{\widehat e_1}{\tau_1\to\tau_2}\\
     \typing{\widehat e_2}{\tau_1}}
    {\typing{\widehat e_1\,\widehat e_2}{\tau_2}}
  \and
  \inferrule*[right=Let]
    {\typing{\widehat e_1}{\tau_1}\\
     \Gamma,x:\tau_1\vdash\widehat e_2:\tau_2}
    {\typing{\letin x{\widehat e_1}{\widehat e_2}}{\tau_2}}
  \and
  \inferrule*[right=If]
    {\typing{\widehat e_1}\tyB\\
     \typing{\widehat e_2}\tau\\
     \typing{\widehat e_3}\tau}
    {\typing{\ite{\widehat e_1}{\widehat e_2}{\widehat e_3}}\tau}
\end{mathpar}

\begin{mathpar}
  \inferrule*[right=Pair]
    {\typing{\widehat e_1}{\tau_1}\\
     \typing{\widehat e_2}{\tau_2}}
    {\typing{\langle\widehat e_1,\widehat e_2\rangle}{\tau_1\times\tau_2}}
  \and
  \inferrule*[right=Fst]
    {\typing{\widehat e}{\tau_1\times\tau_2}}
    {\typing{\kw{fst}\,\widehat e}{\tau_1}}
  \and
  \inferrule*[right=Snd]
    {\typing{\widehat e}{\tau_1\times\tau_2}}
    {\typing{\kw{snd}\,\widehat e}{\tau_2}}
  \and
  \inferrule*[right=Inl]
    {\typing{\widehat e}{\tau_1}}
    {\typing{\kw{inl}\,\widehat e}{\tau_1+\tau_2}}
  \and
  \inferrule*[right=Inr]
    {\typing{\widehat e}{\tau_2}}
    {\typing{\kw{inr}\,\widehat e}{\tau_1+\tau_2}}
  \and
  \inferrule*[right=Sum-Case]
    {\typing{\widehat e}{\tau_1+\tau_2}\\
     \Gamma,x:\tau_1\vdash\widehat e_1:\tau\\
     \Gamma,y:\tau_2\vdash\widehat e_2:\tau}
    {\typing{\scase{\widehat e}{x}{\widehat e_1}{y}{\widehat e_2}}\tau}
\end{mathpar}

\begin{mathpar}
  \inferrule*[right=Nil]
    { }
    {\typing{[]}{\tyL\tau}}
  \and
  \inferrule*[right=Cons]
    {\typing{\widehat e_1}\tau\\
     \typing{\widehat e_2}{\tyL\tau}}
    {\typing{\widehat e_1::\widehat e_2}{\tyL\tau}}
  \and
  \inferrule*[right=List-Case]
    {\typing{\widehat e}{\tyL{\tau_1}}\\
     \typing{\widehat e_0}{\tau_2}\\
     \Gamma,x:\tau_1,xs:\tyL{\tau_1}\vdash\widehat e_1:\tau_2}
    {\typing{\lcase{\widehat e}{\widehat e_0}{x}{xs}{\widehat e_1}}{\tau_2}}
\end{mathpar}

\begin{mathpar}
  \inferrule*[right=Neg]
    {\typing{\widehat e}{\tyR m}}
    {\typing{-\widehat e}{\tyR m}}
  \and
  \inferrule*[right=Add]
    {\typing{\widehat e_1}{\tyR m}\\
     \typing{\widehat e_2}{\tyR m}}
    {\typing{\widehat e_1+\widehat e_2}{\tyR m}}
  \and
  \inferrule*[right=Mul]
    {\typing{\widehat e_1}{\tyR\G}\\
     \typing{\widehat e_2}{\tyR m}}
    {\typing{\widehat e_1\cdot\widehat e_2}{\tyR m}}
  \and
  \inferrule*[right=Div]
    {\typing{\widehat e_1}{\tyR m}\\
     \typing{\widehat e_2}{\tyR\G}}
    {\typing{\widehat e_1/\widehat e_2}{\tyR m}}
  \and
  \inferrule*[right=Cmp]
    {\typing{\widehat e_1}{\tyR\G}\\
     \typing{\widehat e_2}{\tyR\G}}
    {\typing{\widehat e_1<\widehat e_2}\tyB}
\end{mathpar}

For the distribution rules below, $m\in\{\G,\E\}$ and
$\alpha\in\{m,\M\}$.
\begin{mathpar}
  \inferrule*[right=Uniform]
    {\typing{\widehat e_1}{\tyR m}\\
     \typing{\widehat e_2}{\tyR m}}
    {\typing{\draw{uniform}\alpha{\widehat e_1,\widehat e_2}}{\tyR m}}
  \and
  \inferrule*[right=Gaussian]
    {\typing{\widehat e_1}{\tyR m}\\
     \typing{\widehat e_2}{\tyR\G}}
    {\typing{\draw{gaussian}\alpha{\widehat e_1,\widehat e_2}}{\tyR m}}
  \and
  \inferrule*[right=Poisson]
    {\typing{\widehat e}{\tyR m}}
    {\typing{\draw{poisson}\alpha{\widehat e}}{\tyR m}}
  \and
  \inferrule*[right=Exponential]
    {\typing{\widehat e}{\tyR\G}}
    {\typing{\draw{exponential}\alpha{\widehat e}}{\tyR m}}
  \and
  \inferrule*[right=Bernoulli]
    {\typing{\widehat e}{\tyR m}}
    {\typing{\draw{bernoulli}\alpha{\widehat e}}{\tyR m}}
  \and
  \inferrule*[right=Discrete]
    {\typing{\widehat e}{\tyL{\tyR m}}}
    {\typing{\draw{discrete}\alpha{\widehat e}}{\tyR m}}
  \and
  \inferrule*[right=Beta]
    {\typing{\widehat e_1}{\tyR\G}\\
     \typing{\widehat e_2}{\tyR\G}}
    {\typing{\draw{beta}\alpha{\widehat e_1,\widehat e_2}}{\tyR m}}
  \and
  \inferrule*[right=Gamma]
    {\typing{\widehat e_1}{\tyR m}\\
     \typing{\widehat e_2}{\tyR\G}}
    {\typing{\draw{gamma}\alpha{\widehat e_1,\widehat e_2}}{\tyR m}}
\end{mathpar}

The subtyping relation is unchanged:
\begin{mathpar}
  \inferrule*[right=Refl]
    { }
    {\tau<:\tau}
  \and
  \inferrule*[right=Trans]
    {\tau<:\sigma\\\sigma<:\rho}
    {\tau<:\rho}
  \and
  \inferrule*[right=Real-Sub]
    { }
    {\tyR\G<:\tyR\E}
  \and
  \inferrule*[right=Arrow]
    {\sigma_1<:\tau_1\\\tau_2<:\sigma_2}
    {\tau_1\to\tau_2<:\sigma_1\to\sigma_2}
  \and
  \inferrule*[right=Product]
    {\tau_1<:\sigma_1\\\tau_2<:\sigma_2}
    {\tau_1\times\tau_2<:\sigma_1\times\sigma_2}
  \and
  \inferrule*[right=Sum]
    {\tau_1<:\sigma_1\\\tau_2<:\sigma_2}
    {\tau_1+\tau_2<:\sigma_1+\sigma_2}
  \and
  \inferrule*[right=List]
    {\tau<:\sigma}
    {\tyL\tau<:\tyL\sigma}
  \and
  \inferrule*[right=Sub]
    {\typing{\widehat e}\tau\\\tau<:\sigma}
    {\typing{\widehat e}\sigma}
\end{mathpar}
\end{definition}

\subsection{Symbolic States}

\begin{definition}[Symbolic state]
A symbolic environment and a symbolic state have the forms
\[
\begin{aligned}
  \sigma &::=\emptyset\mid\sigma,\ u\sim D(\bar a),\\
  s &::=(\sigma\mid\widehat e).
\end{aligned}
\]
In a state containing $k$ declarations, every affine expression in
$\widehat e$ has coordinates $u_1,\ldots,u_k$. A declaration
$u_i\sim D_i(\bar a_i)$ is well formed when $u_i$ is fresh and its
parameters refer only to $u_1,\ldots,u_{i-1}$. The environment is well typed
when each declaration is well formed and satisfies
$\operatorname{Params}^{\#}_{D_i}(\bar a_i)$, defined below.
In particular, parameters required to have type $\tyR\G$ are constant
affine expressions.
A state is well typed at type $\tau$ when its environment is well typed
and $\emptyset\vdash\widehat e:\tau$. The declarations provide the
coordinates of affine literals; they are not term variables in $\Gamma$.
When a declaration is appended, existing affine expressions are extended
with coefficient zero for the fresh coordinate.
\end{definition}

\subsection{Residual Reduction}
\label{sec:appendix-symbolic-rules}

\paragraph{Structural residual reduction.}
The relation $\rightsquigarrow_{\mathrm{sym}}$ reduces
a residual redex before it is placed in an evaluation context.
\[
\begin{aligned}
(\lambda x.\widehat e)\,\widehat v
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e[x\mapsto\widehat v],\\
(\recfn f x{\widehat e})\,\widehat v
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e[x\mapsto\widehat v,
               f\mapsto\recfn f x{\widehat e}],\\
\letin x{\widehat v}{\widehat e}
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e[x\mapsto\widehat v],\\
\kw{reject}
  &\rightsquigarrow_{\mathrm{sym}}\kw{reject},\\
\ite{\kw{true}}{\widehat e_1}{\widehat e_2}
  &\rightsquigarrow_{\mathrm{sym}}\widehat e_1,\\
\ite{\kw{false}}{\widehat e_1}{\widehat e_2}
  &\rightsquigarrow_{\mathrm{sym}}\widehat e_2,\\
\kw{fst}\,\langle\widehat v_1,\widehat v_2\rangle
  &\rightsquigarrow_{\mathrm{sym}}\widehat v_1,\\
\kw{snd}\,\langle\widehat v_1,\widehat v_2\rangle
  &\rightsquigarrow_{\mathrm{sym}}\widehat v_2.
\end{aligned}
\]
\[
\begin{aligned}
\scase{\kw{inl}\,\widehat v}x{\widehat e_1}y{\widehat e_2}
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e_1[x\mapsto\widehat v],\\
\scase{\kw{inr}\,\widehat v}x{\widehat e_1}y{\widehat e_2}
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e_2[y\mapsto\widehat v],\\
\lcase{[]}{\widehat e_0}x{xs}{\widehat e_1}
  &\rightsquigarrow_{\mathrm{sym}}\widehat e_0,\\
\lcase{\widehat v::\widehat w}{\widehat e_0}x{xs}{\widehat e_1}
  &\rightsquigarrow_{\mathrm{sym}}
    \widehat e_1[x\mapsto\widehat v,xs\mapsto\widehat w].
\end{aligned}
\]

\paragraph{Affine arithmetic and comparisons.}
Write
$a=c_0+\sum_i c_i u_i$ and
$b=d_0+\sum_i d_i u_i$.
Define operations on affine expressions by
\[
\begin{aligned}
\operatorname{neg}(a)
  &=-c_0+\sum_i(-c_i)u_i,\\
\operatorname{add}(a,b)
  &=(c_0+d_0)+\sum_i(c_i+d_i)u_i,\\
\operatorname{scale}(r,a)
  &=rc_0+\sum_i(rc_i)u_i.
\end{aligned}
\]
The corresponding residual reductions are:
\[
\begin{aligned}
-\sym a
  &\rightsquigarrow_{\mathrm{sym}}\sym{\operatorname{neg}(a)},\\
\sym a+\sym b
  &\rightsquigarrow_{\mathrm{sym}}\sym{\operatorname{add}(a,b)},\\
\sym r\cdot\sym a
  &\rightsquigarrow_{\mathrm{sym}}\sym{\operatorname{scale}(r,a)},\\
\sym a\cdot\sym r
  &\rightsquigarrow_{\mathrm{sym}}\sym{\operatorname{scale}(r,a)},\\
\sym a/\sym r
  &\rightsquigarrow_{\mathrm{sym}}
    \sym{\operatorname{scale}(1/r,a)}\qquad(r\ne0),\\
\sym r<\sym q
  &\rightsquigarrow_{\mathrm{sym}}\kw{true}\qquad(r<q),\\
\sym r<\sym q
  &\rightsquigarrow_{\mathrm{sym}}\kw{false}\qquad(r\ge q).
\end{aligned}
\]
Multiplication requires at least one constant operand;
division requires a nonzero constant denominator;
comparison requires two constant operands.
The typing rules ensure the constant-operand requirements for
well-typed residual expressions; domain safety additionally ensures
that reached denominators are nonzero almost surely.

\paragraph{Distribution parameters and symbolic means.}
For $\E$ sampling and $\M$ evaluation, the underlying affine
parameter forms (before componentwise wrapping) are
\[
\begin{aligned}
\kw{uniform}(a,b),\qquad&
\kw{gaussian}(a,r),\\
\kw{poisson}(a),\qquad&
\kw{exponential}(r),\\
\kw{bernoulli}(a),\qquad&
\kw{discrete}([a_i]_{i<n}),\\
\kw{beta}(r,q),\qquad&
\kw{gamma}(a,r).
\end{aligned}
\]
Let $\operatorname{Params}^{\#}_D(\bar a)$ mean that
the parameters have the corresponding form above.
This is a structural requirement, distinct from
the numerical domain condition $\operatorname{Domain}_D$.

The symbolic mean is the following affine expression,
where addition and scaling use the operations defined above:
\[
\begin{aligned}
\operatorname{Mean}^{\#}_{\kw{uniform}}(a,b)
  &=\tfrac12(a+b),\\
\operatorname{Mean}^{\#}_{\kw{gaussian}}(a,r)
  &=a,\\
\operatorname{Mean}^{\#}_{\kw{poisson}}(a)
  &=a,\\
\operatorname{Mean}^{\#}_{\kw{exponential}}(r)
  &=1/r,\\
\operatorname{Mean}^{\#}_{\kw{bernoulli}}(a)
  &=a,\\
\operatorname{Mean}^{\#}_{\kw{discrete}}([a_i]_{i<n})
  &=n+\sum_{i<n}(i-n)a_i,\\
\operatorname{Mean}^{\#}_{\kw{beta}}(r,q)
  &=r/(r+q),\\
\operatorname{Mean}^{\#}_{\kw{gamma}}(a,r)
  &=(1/r)a.
\end{aligned}
\]
These formulas are used under the domain-safety hypotheses
of the soundness results. Mean evaluation reduces by
\[
\inferrule*[right=Mean]
  {\operatorname{Params}^{\#}_D(\bar a)}
  {\avg D{\sym{\bar a}}
    \rightsquigarrow_{\mathrm{sym}}
    \sym{\operatorname{Mean}^{\#}_D(\bar a)}}.
\]

\subsection{Symbolic State Transitions}

The arrows distinguish deterministic transitions from sampling actions.
\textsc{Reduce} and \textsc{Sample-E} have a single successor, whereas
\textsc{Sample-G} specifies a distribution and a continuation mapping
each sampled value to its successor state.

\begin{mathpar}
  \inferrule*[right=Reduce]
    {\widehat e_1\rightsquigarrow_{\mathrm{sym}}
      \widehat e_2}
    {
      (\sigma\mid\widehat C[\widehat e_1])\\
      \deterministicarrow_{\mathrm{sym}}
      (\sigma\mid\widehat C[\widehat e_2])
    }
  \and
  \inferrule*[right=Sample-E]
    {u\notin\operatorname{dom}(\sigma) \\
     \operatorname{Params}^{\#}_D(\bar a)}
    {
      (\sigma\mid\widehat C[
        \draw D\E{\sym{\bar a}}])\\
      \deterministicarrow_{\mathrm{sym}}
      (\sigma,u\sim D(\bar a)\mid
        \widehat C[\sym u])
    }
  \and
  \inferrule*[right=Sample-G]
    {\operatorname{Domain}_D(\bar r)}
    {
      (\sigma\mid\widehat C[
        \draw D\G{\sym{\bar r}}])\\
      \samplingarrow{D(\bar r)}_{\mathrm{sym}}
      \bigl(r\mapsto
      (\sigma\mid\widehat C[\sym r])\bigr)
    }
\end{mathpar}

In \textsc{Sample-G}, $r$ is sampled according to
$D(\bar r)$; the continuation specifies the resulting state,
not an arbitrary choice of $r$.
All parameters $\bar r$ are constant values, including
constant list entries for the discrete primitive.

In \textsc{Sample-E}, $\sym u$ wraps the affine expression
for the newly introduced coordinate. Existing affine
expressions are extended with coefficient zero for $u$.
The step records a distribution without evaluating its
domain condition at an unknown valuation; domain safety
is imposed separately in the soundness statements.

A state whose residual expression is a value is terminal.
Apart from the rejection self-loop, expressions for which
no rule applies are stuck. Only \textsc{Sample-G} contributes
an event to the retained trace.

\subsection{Lifting, Realization, and Initialization}
\label{def:appendix-symbolic-maps}

\begin{definition}[Lifting\leanref{symbolic-lifting}]
Write $L(e):=\mathsf{lift}(e)$. Lifting maps source expressions to
residual expressions with no symbolic coordinates. For a real literal,
\[
  L(r)=\sym{\underline r},\qquad \underline r=r\quad\text{(the constant affine expression).}
\]
Its remaining clauses are:
\[
\begin{aligned}
  L\bigl(x\bigr)&=x,\\
  L\bigl(()\bigr)&=(),\\
  L\bigl(\kw{true}\bigr)&=\kw{true},\\
  L\bigl(\kw{false}\bigr)&=\kw{false},\\
  L\bigl(\kw{reject}\bigr)&=\kw{reject},\\
  L\bigl([]\bigr)&=[],\\
  L\bigl(\lambda x.e\bigr)&=\lambda x.L(e),\\
  L\bigl(\recfn g x{e}\bigr)&=\recfn g x{L(e)},\\
  L\bigl(e_1\,e_2\bigr)&=L(e_1)\,L(e_2),\\
  L\bigl(\letin x{e_1}{e_2}\bigr)&=\letin x{L(e_1)}{L(e_2)},\\
  L\bigl(\ite{e_1}{e_2}{e_3}\bigr)&=\ite{L(e_1)}{L(e_2)}{L(e_3)},\\
  L\bigl(-e\bigr)&=-L(e).
\end{aligned}
\]

\[
\begin{aligned}
  L\bigl(\langle e_1,e_2\rangle\bigr)&=\langle L(e_1),L(e_2)\rangle,\\
  L\bigl(\kw{fst}\,e\bigr)&=\kw{fst}\,L(e),\\
  L\bigl(\kw{snd}\,e\bigr)&=\kw{snd}\,L(e),\\
  L\bigl(\kw{inl}\,e\bigr)&=\kw{inl}\,L(e),\\
  L\bigl(\kw{inr}\,e\bigr)&=\kw{inr}\,L(e),\\
  L\bigl(\scase{e}x{e_1}y{e_2}\bigr)&=\scase{L(e)}x{L(e_1)}y{L(e_2)},\\
  L\bigl(e_1::e_2\bigr)&=L(e_1)::L(e_2),\\
  L\bigl(\lcase{e}{e_0}x{xs}{e_1}\bigr)&=\lcase{L(e)}{L(e_0)}x{xs}{L(e_1)},\\
  L(e_1+e_2)&=L(e_1)+L(e_2),\\
  L(e_1\cdot e_2)&=L(e_1)\cdot L(e_2),\\
  L(e_1/e_2)&=L(e_1)/L(e_2),\\
  L(e_1<e_2)&=L(e_1)<L(e_2),\\
  L\bigl(D^\alpha(e_1,\ldots,e_j)\bigr)
    &=D^\alpha(L(e_1),\ldots,L(e_j)).
\end{aligned}
\]
\end{definition}

\begin{definition}[Realization\leanref{symbolic-realization}]
For a valuation $\rho:\{u_1,\ldots,u_k\}\to\Real$, write
$R_\rho(\widehat e):=\mathsf{realize}_\rho(\widehat e)$.
Realization evaluates affine literals to ordinary real literals:
\[
 R_\rho\left(\sym{c_0+\sum_{i=1}^k c_i u_i}\right)
   =c_0+\sum_{i=1}^k c_i\rho(u_i).
\]
Its remaining clauses are:
\[
\begin{aligned}
  R_\rho\bigl(x\bigr)&=x,\\
  R_\rho\bigl(()\bigr)&=(),\\
  R_\rho\bigl(\kw{true}\bigr)&=\kw{true},\\
  R_\rho\bigl(\kw{false}\bigr)&=\kw{false},\\
  R_\rho\bigl(\kw{reject}\bigr)&=\kw{reject},\\
  R_\rho\bigl([]\bigr)&=[],\\
  R_\rho\bigl(\lambda x.\widehat e\bigr)&=\lambda x.R_\rho(\widehat e),\\
  R_\rho\bigl(\recfn g x{\widehat e}\bigr)&=\recfn g x{R_\rho(\widehat e)},\\
  R_\rho\bigl(\widehat e_1\,\widehat e_2\bigr)&=R_\rho(\widehat e_1)\,R_\rho(\widehat e_2),\\
  R_\rho\bigl(\letin x{\widehat e_1}{\widehat e_2}\bigr)&=\letin x{R_\rho(\widehat e_1)}{R_\rho(\widehat e_2)},\\
  R_\rho\bigl(\ite{\widehat e_1}{\widehat e_2}{\widehat e_3}\bigr)&=\ite{R_\rho(\widehat e_1)}{R_\rho(\widehat e_2)}{R_\rho(\widehat e_3)},\\
  R_\rho\bigl(-\widehat e\bigr)&=-R_\rho(\widehat e).
\end{aligned}
\]

\[
\begin{aligned}
  R_\rho\bigl(\langle \widehat e_1,\widehat e_2\rangle\bigr)&=\langle R_\rho(\widehat e_1),R_\rho(\widehat e_2)\rangle,\\
  R_\rho\bigl(\kw{fst}\,\widehat e\bigr)&=\kw{fst}\,R_\rho(\widehat e),\\
  R_\rho\bigl(\kw{snd}\,\widehat e\bigr)&=\kw{snd}\,R_\rho(\widehat e),\\
  R_\rho\bigl(\kw{inl}\,\widehat e\bigr)&=\kw{inl}\,R_\rho(\widehat e),\\
  R_\rho\bigl(\kw{inr}\,\widehat e\bigr)&=\kw{inr}\,R_\rho(\widehat e),\\
  R_\rho\bigl(\scase{\widehat e}x{\widehat e_1}y{\widehat e_2}\bigr)&=\scase{R_\rho(\widehat e)}x{R_\rho(\widehat e_1)}y{R_\rho(\widehat e_2)},\\
  R_\rho\bigl(\widehat e_1::\widehat e_2\bigr)&=R_\rho(\widehat e_1)::R_\rho(\widehat e_2),\\
  R_\rho\bigl(\lcase{\widehat e}{\widehat e_0}x{xs}{\widehat e_1}\bigr)&=\lcase{R_\rho(\widehat e)}{R_\rho(\widehat e_0)}x{xs}{R_\rho(\widehat e_1)},\\
  R_\rho(\widehat e_1+\widehat e_2)&=R_\rho(\widehat e_1)+R_\rho(\widehat e_2),\\
  R_\rho(\widehat e_1\cdot\widehat e_2)&=R_\rho(\widehat e_1)\cdot R_\rho(\widehat e_2),\\
  R_\rho(\widehat e_1/\widehat e_2)&=R_\rho(\widehat e_1)/R_\rho(\widehat e_2),\\
  R_\rho(\widehat e_1<\widehat e_2)&=R_\rho(\widehat e_1)<R_\rho(\widehat e_2),\\
  R_\rho\bigl(D^\alpha(\widehat e_1,\ldots,\widehat e_j)\bigr)
    &=D^\alpha(R_\rho(\widehat e_1),\ldots,R_\rho(\widehat e_j)).
\end{aligned}
\]
\end{definition}

In both definitions, the distribution clause applies to every primitive,
with arities
\[
\begin{aligned}
 j&=1 &&\text{for }D\in\{\kw{poisson},\kw{exponential},\kw{bernoulli},\kw{discrete}\},\\
 j&=2 &&\text{for }D\in\{\kw{uniform},\kw{gaussian},\kw{beta},\kw{gamma}\}.
\end{aligned}
\]
The discrete primitive takes a list expression as its single argument.
The mode $\alpha\in\{\G,\E,\M\}$ and all program-variable binders are
preserved. Realization does not substitute for program variables.

\begin{definition}[Initialization]
For a source expression $e$, define
\[
  \mathsf{init}(e):=(\emptyset\mid\mathsf{lift}(e)).
\]
\end{definition}
With $()$ denoting the empty valuation,
$\mathsf{realize}_{()}(\mathsf{lift}(e))=e$\leanref{symbolic-realize-lift}.

\section{Miscellaneous}\label{sec:appendix-misc}
\paragraph{When Expectations Are Undefined}
\begin{example}
In the coin-flipping example (cf. \Cref{ex:coin-flip}), each terminating $\G$-trace has positive probability. A trace can also contain continuous draws:
\begin{lstlisting}
let u = uniform[G](-1, 1) in
uniform[E](0, 2) / u
\end{lstlisting}
This program has an undefined global expectation. Yet for each fixed $u\ne0$,
the remaining expression has mean $1/u$, exactly the value returned by the
transformed program. Thus determinization is tracewise sound for this program, but the global expectation preservation theorem does not apply. 

Moreover, note that every individual value of $u$ has probability zero, so conditioning on a trace cannot simply mean dividing by its probability, hence the disintegration-based definition of conditional output distributions in~\Cref{eq:disintegration}.
\end{example}

\begin{example}
Consider
\begin{lstlisting}
let u = uniform[G](0, 1) in
let s = 2 * bernoulli[G](1/2) - 1 in
s / u + uniform[E](-1, 1)
\end{lstlisting}
The program returns almost surely and is domain-safe: although division is
undefined when $u=0$, this event has probability zero under the
continuous uniform distribution. However,
\[
  \int_0^1 \frac{1}{u}\,du=\infty.
\]
When $s=1$, the term $s/u$ gives the return value an infinite positive part;
when $s=-1$, it gives the return value an infinite negative part. Since each
sign occurs with probability $1/2$, both parts have infinite expectation, so
the program's global expectation is undefined.

Determinization is nevertheless valid and tracewise sound for this program. Determinization replaces the final uniform draw by its mean zero and therefore
returns exactly $s/u$ for some fixed $\G$-trace. The global expectation preservation theorem does not
apply because its hypothesis requires the source expectation to be
well-defined in the extended reals. Likewise, the variance theorem does not
apply because the program has an infinite second moment.
\end{example}

\paragraph{Domain safety and missing probability.}
\begin{example}
The following program is not domain-safe:
\begin{lstlisting}
let x = bernoulli[G](1/2) in
1 / x
\end{lstlisting}
With probability $1/2$, the sample is $x=0$, at which point division by zero
causes execution to get stuck. Because this invalid operation occurs with
positive probability, it cannot be ignored by the almost-sure condition in
domain safety. When $x=1$, the program successfully returns $1$, so
\[
  \law e=\frac12\delta_1,
  \qquad
  \law e(\Real)=\frac12.
\]
The missing probability mass comes from an invalid operation rather than
rejection or divergence.
\end{example}

\begin{example}
The following well-typed program $e$ is not domain-safe:
\begin{lstlisting}
let u = gaussian[E](0, 1) in uniform[E](0, u)
\end{lstlisting}
When $u<0$, the uniform distribution's parameters are invalid and execution gets
stuck. The program returns with probability $1/2$; conditioned on returning,
its expected output is half the mean of a standard Gaussian conditioned to be
positive. Determinization sets $u=0$ and returns the mean of
$\kw{uniform}(0,0)$, which is zero.
Thus the domain-safety assumption is necessary, because:
\[
 \Expect_{\mathrm{ret}}[e]=\frac{1}{\sqrt{2\pi}}
 \qquad\text{but}\qquad
 \Expect_{\mathrm{ret}}[\trans e]=0.
\]
\end{example}

\paragraph{Why domain safety is necessary.}
Tracewise soundness and expectation preservation require domain safety
(\cref{thm:trace-soundness,thm:expectation}). Without domain safety, replacing an $\E$-mode sample by its mean can change whether a later operation is defined, and therefore change which executions contribute to the return-conditioned distribution.

For example,
\begin{lstlisting}
let u = gaussian[E](0, 1) in
uniform[E](0, u)
\end{lstlisting}
is not domain-safe: executions with $u<0$ become stuck. Conditioning on successful return therefore implicitly conditions $u$ to be positive, giving
\[
\Expect_{\mathrm{ret}}[e]
=
\frac{1}{2}\Expect[u\mid u>0]
=
\frac{1}{\sqrt{2\pi}}.
\]
Determinization instead replaces $u$ by its unconditional mean $0$, yielding
\[
\Expect_{\mathrm{ret}}[\trans e]=0.
\]
Thus domain safety prevents determinization from changing which executions are semantically valid and, consequently, which executions contribute to the return-conditioned output distribution.

\section{Full Benchmarks (for RQ2)}\label{sec:appendix-infinite-benchmarks}

For \texttt{2d-walk}, \texttt{bimodal}, \texttt{random-walk-1d}, and \texttt{vasicek}, we replace fixed iteration bounds with a \texttt{flip(1/2)} continuation guard. The number of iterations is geometrically distributed, with mean one and no finite upper bound. These loops terminate almost surely and retain infinitely many reachable states after determinization. Their stopping coins remain random; in particular, \texttt{vasicek} is partially determinized and retains variance from its stopping time. The \texttt{hmm} benchmark retains its fixed sequence of eight observations and becomes finite-state after determinization.

For \texttt{cont-sampling}, we draw the downward-step probability from $\kw{uniform}(1/3,1)$, so the walk moves toward zero with probability $2/3$ at each step. Starting from 10, it terminates almost surely after 30 steps on average. This bias gives a finite source expectation of 5 and variance $5/2$; determinization returns 5 on every terminating run. The unbiased walk has an undefined expectation and infinite second moment, so it cannot serve as a finite-moment variance benchmark.

  [] => 1 / 0
  | x :: rest =>
      if i < 1 then x else index rest (i - 1)
in

let equal = fun x => fun y =>
  if x <= y then y <= x else false
in

let emit = 0.05 :: 0.25 :: [] in
let dwell_rate = 0.8 :: 1.2 :: [] in
let trans = 0.05 :: 0.5 :: [] in
let initial_state = 0 in
let data = 0 :: 0 :: 0 :: 0 :: 0 :: 0 :: 0 :: 0 :: [] in

let hmm = rec hmm z => fun data =>
  match data with
  [] => 0
  | data :: remaining_data =>

      let y = bernoulli(index emit z) in
      let _ = observe(equal y data) in

      let dwell = exponential(index dwell_rate z) in

      let next_z = bernoulli(index trans z) in

      let rest = hmm next_z remaining_data in

      dwell + rest
in

hmm initial_state data
\end{lstlisting}
