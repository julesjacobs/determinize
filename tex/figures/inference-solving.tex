\textbf{(a) Shape unification}\leanref{type-shape-unification}

Erase real annotations and unify the shapes on both sides of every
subtype constraint, rejecting constructor clashes and occurs-check
violations. Let $\theta$ be the resulting most general shape substitution.

\smallskip
\textbf{(b) Decoration}\leanref{type-affinity-decoration}

Replace each type variable $X$ by $\theta X$ with a fresh annotation
variable at each real leaf. Reuse the same decoration at every
occurrence of $X$; use distinct annotation variables for distinct
type variables. Preserve existing real annotations.
\end{minipage}

\smallskip
\textbf{(c) Subtype constraint reduction}\leanref{subtype-constraint-reduction}
\[
\begin{gathered}
\tyR a<:\tyR b
  \;\leadsto\;\{a\le b\}
  \qquad
\tyL\tau<:\tyL\sigma
  \;\leadsto\;\{\tau<:\sigma\}\\[2pt]
\chi<:\chi
  \;\leadsto\;\varnothing
  \quad(\chi\text{ is }\tyU,\tyB\text{, or a shape variable})\\[2pt]
(\tau_1\to\tau_2)<:(\sigma_1\to\sigma_2)
  \;\leadsto\;\{\sigma_1<:\tau_1,\;\tau_2<:\sigma_2\}\\[2pt]
(\tau_1\star\tau_2)<:(\sigma_1\star\sigma_2)
  \;\leadsto\;\{\tau_1<:\sigma_1,\;\tau_2<:\sigma_2\}
  \quad(\star\in\{\times,+\}).
\end{gathered}
\]

\medskip
\textbf{(d) Mode constraint solving}\leanref{affinity-solving}
\[
\inferrule{a\le b\\a=\E}{b:=\E}
\qquad\qquad
\inferrule{a\le b\\b=\G}{a:=\G}
\]
\caption{Constraint solving, in the order (a)--(d). Conflicting mode
assignments cause inference to fail. Unassigned annotation variables
default to $\E$; remaining shape variables become $\tyU$ at read-back.}
\label{fig:inference-solving}
\Description{Shape unification rejects constructor clashes and cyclic shapes.
Decoration assigns annotation variables to the real leaves of each type
variable's unified shape. Subtype reduction yields annotation inequalities,
which are solved by propagation.}
