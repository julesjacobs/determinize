let walk =
  rec walk times => fun t => fun y =>

    | [] => []

\par\smallskip
The source returns a random path; after replacement it returns
$[(0,0),(1,0),\ldots,(6,0)]$.
\caption{A Gaussian random walk from~\cite{vakar2019domain}.
Both programs return the complete list of sampled time--position pairs.}
\label{fig:intro-gaussian-walk}
\Description{The source recursively visits times one through six. At each time,
it draws a Gaussian position whose mean is the previous position and whose
variance is the elapsed time, and returns every time--position pair. Replacing
every draw by its mean leaves the position fixed at zero, so the transformed
program returns the deterministic path containing positions zero at every time.
